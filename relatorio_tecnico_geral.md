## Mapa do código

```
app/
├── main.py                 # app, CORS, middlewares, routers, docs off em produção
├── core/                   # camada de autenticação/autorização SEPARADA
│   ├── config.py           # BaseSettings (.env), sem segredos padrão
│   ├── security.py         # bcrypt, JWT, TOTP, ROLE_SCOPES
│   ├── dependencies.py     # require_roles, ownership (único ponto), escopos
│   └── middleware.py       # headers de segurança, rate limiters
├── database/               # engine, sessão, repositório de usuários
├── models/                 # tabelas SQLModel e schemas Pydantic
├── routes/                 # appointments, auth, admin, lab, web
└── templates/              # base.html + agenda.html (herança, auto-escape)
```
